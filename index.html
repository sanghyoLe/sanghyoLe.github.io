최근에는 Notion에 있는 사내 문서를 Slack에서 찾아볼 수 있는 위키봇을 만들었습니다. 지금은 개발팀과 디자인·기획팀에서 함께 쓰고 있습니다.

토큰 만료로 작성 중인 내용이 사라지는 문제 해결

계약을 작성하다 토큰이 만료되면 입력한 내용이 사라지는 문제가 있었습니다. 401 응답을 받으면 토큰을 새로 발급받고, 실패한 요청을 원래 내용 그대로 다시 보내도록 수정했습니다. 여러 요청이 동시에 실패해도 재발급은 한 번만 하고, 나머지는 큐에서 기다렸다가 재시도합니다. 재시도가 끝없이 반복되거나 비밀번호 오입력까지 재발급으로 처리되지 않도록 예외도 뒀습니다.

토큰 조회·재발급·세션 정리 함수를 외부에서 받도록 만들어, 인증 방식이 다른 axios 인스턴스 5개에서 같은 코드를 씁니다. 세션을 정리할 때는 WebSocket도 끊습니다. 연결을 남겨두면 만료된 토큰으로 10초마다 재접속을 시도했기 때문입니다.

Axios interceptor, Promise queue, STOMP/SockJS

탄소회계 104개국 확장

계산식과 참조 데이터, 지원 국가 목록을 서버에서 관리해 프론트엔드와 백엔드가 같은 값을 쓰도록 했습니다. GS 계산 방식을 쓰는 국가는 서버에 데이터를 추가하면 프론트엔드를 다시 배포하지 않아도 지원할 수 있습니다. PDF 내보내기와 한국·미국 화면의 다국어 지원도 맡았습니다.

추상 클래스 + Factory, 시스템 코드 기반 규칙 관리, React.lazy 코드 스플리팅
